# ⚙️ Installation du projet

## 1. Installer les dépendances

```bash
npm install
```

---

## 2. Lancer le projet

```bash
npm run dev
```

---

## 3. Ajouter un composant shadcn

```bash
npx shadcn@latest add button
```

---

## 4. Modifier le site

* Couleurs → `globals.css`
* Textes → `/messages`
* Pages → `/app`

---

💡 Conseil :
Tout est déjà configuré, il suffit d’adapter le contenu.
