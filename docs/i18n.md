# 🌍 Gestion des langues (i18n)

## 1. Ajouter une langue

Va dans :

👉 `i18n/routing.ts`

Ajoute la nouvelle langue :

```ts
locales: ["fr", "en"]
```

---

## 2. Ajouter les traductions

Va dans :

```
/messages/
```

Crée un fichier :

```
en.json
```

---

## 3. Structure des traductions

Exemple :

```json
{
  "Legal": {
    "title": "Titre de la page",
    "intro": "Texte d'introduction"
  }
}
```

---

## 4. Utilisation dans les composants

```ts
const t = useTranslations("Legal");

t("title");
```

---

## 5. Bonnes pratiques

* Regrouper par page (`Legal`, `Home`, etc)
* Utiliser des clés claires
* Ne jamais écrire du texte en dur dans les composants

---

💡 Conseil :
Tu peux dupliquer `fr.json` pour créer une nouvelle langue.

## ⚠️ Ajouter une nouvelle page (IMPORTANT)

Quand tu crées une nouvelle page (ex: `/legal`, `/privacy`, etc),
tu dois aussi la déclarer dans :

👉 `i18n/routing.ts`

---

### Exemple

```ts
export const pathnames = {
  "/": "/",
  "/legal": "/legal",
  "/privacy": "/privacy",
  "/contact": "/contact",
} as const;
```

---

### Pourquoi ?

Next-intl utilise ce fichier pour :

* gérer les routes multilingues
* générer les bons liens (`/fr/legal`, `/en/legal`)
* charger correctement les traductions

---

### ❌ Si tu oublies

Tu peux avoir des erreurs comme :

```
MISSING_MESSAGE: Could not resolve `Legal`
```

---

### ✅ Bon réflexe

👉 Toujours ajouter ta page ici après création

---

💡 Astuce :
Pré-déclare toutes tes pages dès le départ pour éviter les oublis.
